# Daydesk Notes

Daydesk Notes is a Windows desktop widget for daily tasks and notes.

## Latest release

**Version 1.2.0** adds Burgundy Light and Burgundy Dark, a refreshed quick-add layout, and a matching app icon. Select a theme under **Settings → Appearance**.

[View the latest release](https://github.com/raakhshakhs/Udy/releases/latest) · [Download the Windows x64 installer](https://github.com/raakhshakhs/Udy/releases/latest/download/Daydesk-Notes-Setup-1.2.0-x64.exe)

For an existing installation with in-app updates, right-click the Daydesk tray icon and choose **Check for updates**. When the download finishes, choose **Restart and install update**.
