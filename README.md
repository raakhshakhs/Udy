# Daydesk Notes

Daydesk Notes is a Windows desktop widget for daily tasks and notes.

## Latest release

**Version 1.4.0** adds date-aware quick capture, Today and Later planning, three task priorities, drag reordering, carry-forward, daily or weekly repeats, reminders, focus timers, and a visual board for notes and media. Customize the compact task list under **Settings**.

[View the latest release](https://github.com/raakhshakhs/Udy/releases/latest) · [Download the Windows x64 installer](https://github.com/raakhshakhs/Udy/releases/latest/download/Daydesk-Notes-Setup-1.4.0-x64.exe)

To update an existing installation, right-click the Daydesk tray icon and choose **Check for updates**. When the download finishes, choose **Restart and install update**.
