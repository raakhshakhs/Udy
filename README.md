# Daydesk Notes

Daydesk Notes is a Windows desktop widget for daily tasks and notes.

## Latest release

**Version 1.3.0** opens in a compact desktop panel. Check off tasks directly in Today and use the arrow in the header to switch between compact and expanded sizes. Choose Burgundy Light or Burgundy Dark under **Settings → Appearance**.

[View the latest release](https://github.com/raakhshakhs/Udy/releases/latest) · [Download the Windows x64 installer](https://github.com/raakhshakhs/Udy/releases/latest/download/Daydesk-Notes-Setup-1.3.0-x64.exe)

For an existing installation with in-app updates, right-click the Daydesk tray icon and choose **Check for updates**. When the download finishes, choose **Restart and install update**.
